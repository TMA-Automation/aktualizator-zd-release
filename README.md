# Potwierdzenie zamówienia — wydania

Repozytorium wydań aplikacji **Potwierdzenie zamówienia** (TMA Automation).
Kod źródłowy jest w prywatnym repozytorium
[`TMA-Automation/potwierdzenie-zamowienia`](https://github.com/TMA-Automation/potwierdzenie-zamowienia).

To repozytorium jest publiczne wyłącznie po to, żeby aplikacja mogła anonimowo
sprawdzać dostępność nowej wersji (`version.txt`) i pobierać plik wykonywalny
z wydania — nie leży tu żaden kod.

## Instalacja

Pobierz `PotwierdzenieZamowienia.exe` z [najnowszego wydania](../../releases/latest)
i przeczytaj [Instrukcja.md](Instrukcja.md) — zawiera ważne uwagi (m.in. nie uruchamiać
z OneDrive/Pulpitu/Dokumentów).

## Aktualna wersja

Zobacz [`version.txt`](version.txt).
