# Aktualizator ZD — wydania

Repozytorium wydań aplikacji **Aktualizator ZD** (TMA Automation) — wcześniej
„Potwierdzenie zamówienia”. Kod źródłowy jest w prywatnym repozytorium
[`TMA-Automation/aktualizator-zd`](https://github.com/TMA-Automation/aktualizator-zd).

To repozytorium jest publiczne wyłącznie po to, żeby aplikacja mogła anonimowo
sprawdzać dostępność nowej wersji (`version.txt`) i pobierać plik wykonywalny
z wydania — nie leży tu żaden kod.

## Instalacja

Pobierz `AktualizatorZD.exe` z [najnowszego wydania](../../releases/latest)
i przeczytaj [Instrukcja.md](Instrukcja.md) — zawiera ważne uwagi (m.in. nie uruchamiać
z OneDrive/Pulpitu/Dokumentów). Ta sama instrukcja jest dostępna w aplikacji
(odnośnik „Instrukcja” w prawym górnym rogu albo klawisz F1).

## Aktualna wersja

Zobacz [`version.txt`](version.txt).
